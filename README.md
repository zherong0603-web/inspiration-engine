# 灵感引擎 ✨

AI驱动的新媒体内容创作工具，帮助创作者快速生成个性化短视频口播稿。

## 🎯 产品简介

灵感引擎是一个专为小红书、抖音等平台内容创作者设计的AI工具，通过三步流程帮你快速产出高质量内容：

1. **IP人物设定** - 定义你的专业领域和创作风格
2. **选题推荐** - 获取实时热点，智能匹配适合你的话题
3. **内容创作** - AI生成符合你风格的1-3分钟口播稿

## 🚀 快速开始

### 使用方法

1. 用浏览器打开 `index.html` 文件
2. 在"IP设定"页面填写你的信息
3. 在"选题推荐"中选择感兴趣的话题
4. 在"内容创作"中生成口播稿

### 两种模式

**演示模式**（推荐新手）
- 无需配置，开箱即用
- 基于模板快速生成
- 适合快速体验产品

**API模式**（推荐专业用户）
- 需要Claude API密钥
- 生成更个性化的内容
- 质量更高，更符合你的风格

## 💡 核心功能

### IP人物设定
- 定义专业领域、写作风格、目标受众
- 上传知识库，让AI理解你的表达习惯
- 实时预览AI提取的人设特征
- 透明化展示，避免"黑盒"问题

### 选题推荐
- 展示小红书、抖音实时热点
- 智能计算选题适配度
- 按平台、热度筛选
- 一键选择进入创作

### 内容创作
- 1-3分钟短视频口播稿
- 可调节专业度、口语化、情感浓度
- 支持重新生成和风格调整
- 一键复制到剪贴板

## 🛠️ 技术说明

### 技术栈
- 纯前端实现：HTML + CSS + JavaScript
- 无需服务器，本地即可运行
- 数据保存在浏览器localStorage

### API配置（可选）

如需使用API模式：

1. 访问 [Anthropic官网](https://console.anthropic.com/) 申请API密钥
2. 在"设置"页面输入密钥
3. 切换到API模式即可使用
